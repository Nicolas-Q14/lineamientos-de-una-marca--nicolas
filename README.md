# LUMÉ Beauty — Brand Book

Proyecto académico de una tienda/brand book de maquillaje desarrollado con HTML, CSS, JavaScript y Bootstrap 5.

## 10 secciones
1. Inicio
2. Identidad de marca
3. Logotipo
4. Construcción del logotipo
5. Paleta cromática
6. Tipografía
7. Tienda / productos
8. Experiencia de marca
9. Campaña
10. Contacto

## Bootstrap
Se utiliza Bootstrap 5 mediante CDN y el sistema `.container`, `.row`, `.col-*` para el Grid System responsive.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube `index.html`, la carpeta `css` y la carpeta `js`.
3. En GitHub entra a **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige `main` y carpeta `/ (root)`.
6. Guarda y espera a que GitHub genere el enlace.

No necesita Node.js ni instalación local para funcionar.
